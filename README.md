# Симметрия NF₃
Высшая алгебра, группа 7. Александр Бортулев, Глеб Егоренков, Николай Чемякин.

[Сайт проекта на GitHub Pages](https://bortulev-coder.github.io/-1-/)

Главная страница — `index.html`. Сайт открывается локально и работает из подпапки репозитория. В меню «Моя часть» — подготовка Александра, рукописные перестановки и репетиция выступления. «Весь проект» содержит отчёт, модель, анимации и материалы команды. Фотография рукописи будет добавлена после получения.

Для публикации из ветки выберите в Settings → Pages источник Deploy from a branch, ветку main и каталог / (root).
