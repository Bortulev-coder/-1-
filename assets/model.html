Трифторид азота NF₃

Интерактивная модель группы C₃ᵥ ≅ S₃

Азот N1 находится над плоскостью трех атомов фтора F2, F3, F4.
Азот N₁Фтор F₂, F₃, F₄Ось C₃ — золотая

Перетаскивание — поворот камеры. Колесо мыши — масштаб. Метки перемещаются вместе с атомами.

Серые контуры обозначают исходные положения. Все операции начинаются с одной исходной конфигурации.

σ₁ содержит N₁F₂, σ₂ — N₁F₃, σ₃ — N₁F₄. Положительный поворот идёт против часовой стрелки при наблюдении с +z. Нумерация совпадает с отчётом. Центра инверсии, горизонтальной плоскости и дополнительных зеркально-поворотных осей нет.

Геометрия: r(N–F) = 1,365 Å, ∠F–N–F = 102,37°. Координаты построены из этих параметров с точной симметрией C₃ᵥ. Источник — NIST CCCBDB. Модель работает без подключения к интернету.
